# 💜 ProductivityAI — Personal Productivity Dashboard

A modern, responsive productivity dashboard designed to help users manage daily tasks, track personal goals, improve focus, and monitor productivity through interactive charts.

Built using HTML, CSS, JavaScript, Chart.js, and Browser Local Storage, this project provides a simple and organized workspace for personal productivity.

## ✨ Features

- 📋 **Task Management** — Create, edit, delete, and complete tasks.
- 🎯 **Goal Tracking** — Set personal goals and track milestone progress.
- ⏱️ **Focus Timer** — Use 25-minute focus sessions and 5-minute or 15-minute breaks.
- 📊 **Productivity Analytics** — Visualize completed tasks and task status using interactive charts.
- 🤖 **Smart Recommendations** — Get rule-based suggestions based on pending tasks and priorities.
- 💾 **Local Storage** — Automatically save tasks, goals, and productivity data in the browser.
- 🌙 **Theme Toggle** — Switch between dark and light themes.
- 📥 **CSV Export** — Export task information as a CSV file.
- 📱 **Responsive Design** — Access the dashboard on desktop, tablet, and mobile devices.
- 🎨 **Modern UI** — Purple and blue colors, animations, and a clean dashboard layout.
